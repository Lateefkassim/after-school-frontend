# After School Classes - Vue.js App (CST3144)

Front end for the after school classes app. Built with Vue.js and Vite. It gets its data from the Express.js API using `fetch`.

## Run locally

```sh
npm install
npm run dev
```

The backend must be running too. The API address is the `API` constant at the top of `src/App.vue`. Change it to the render.com address before deploying to GitHub Pages.
